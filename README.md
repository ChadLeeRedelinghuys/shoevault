\# ShoeVault 👟



ShoeVault is an ASP.NET Core MVC web application for managing and showcasing running and hiking footwear.  

The application allows users to browse shoes by category, view details, and manage shoes with multiple images.  

It also includes secure authentication and a full password reset system via email.



---



\## Features



\- User registration and login using ASP.NET Identity

\- Secure password reset via email (Gmail SMTP)

\- Categorised shoes:

&nbsp; - Road Running

&nbsp; - Trail Running

&nbsp; - Hiking Shoes

&nbsp; - Hiking Boots

\- Add, edit, and delete shoes

\- Upload multiple images per shoe

\- "Latest Editions" section highlighting newest shoes

\- NEW badge for recently added shoes

\- Responsive layout with modern styling



---



\## Technologies Used



\- ASP.NET Core MVC

\- C#

\- Entity Framework Core

\- SQLite Database

\- ASP.NET Identity Authentication

\- SMTP Email Integration
